CapCut 2 Light V5 - projeto preparado para gerar APK Android sem Android Studio

1. Crie um repositorio vazio no github.com (pode ser privado).
2. Envie TODO o conteudo desta pasta para a raiz do repositorio, incluindo a pasta oculta .github/workflows.
3. Abra a aba Actions do repositorio. Se solicitado, habilite Actions.
4. Abra 'Criar APK do CapCut 2' e clique em 'Run workflow'.
5. Quando concluir, clique na execucao e baixe o artifact 'CapCut2-Light-V5-APK'.
6. Extraia esse artifact e instale app-debug.apk no Android.

O processo precisa de uma conta GitHub e conexao com a internet. Nao e possivel gerar o APK so com este ZIP: o build e executado no GitHub Actions.

A exportacao MP4 dentro do editor depende dos codecs disponibilizados pelo Android WebView; teste em seu telefone.
